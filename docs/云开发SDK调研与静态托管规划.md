# 云开发Web SDK调研 & 看板静态托管规划
## 一、Web SDK调研
1. 用途：浏览器前端页面直接访问云开发资源，调用boardStat云函数，获取统计数据渲染看板。
2. 接入流程
    1）页面引入云开发web‑sdk脚本
    2）代码初始化云开发环境，填写环境ID
    3）调用云函数 boardStat 获取业务数据
3. 限制条件
    网页调用云函数会触发跨域，**需要管理员账号登录云开发控制台，配置Web安全来源域名**。本步骤本人无管理员权限，交由项目管理员执行。

## 二、web‑dashboard看板静态托管规划
1. 方案：使用微信云开发静态网站托管，部署管理员看板页面。
2. 部署步骤规划
    1）准备web‑dashboard全部静态资源(html/js/css)
    2）使用cloudbase cli工具上传全部静态文件
    3）访问云开发分配的静态域名，打开管理看板
3. 前置依赖（管理员操作）
    ①管理员开启静态网站托管服务
    ②管理员配置Web安全来源域名，解决网页调用云函数跨域问题。
