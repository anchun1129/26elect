# 电动车乱停监测系统 UI设计规范文档
## 1. 色彩规范
### 业务主色
- 主品牌色：#1677FF（蓝色，按钮、重点操作）
- 成功状态：#52C41A（处理完成、正常）
- 警告状态：#FAAD14（待处理提醒）
- 错误状态：#F5222D（异常、删除）

### 文本颜色
- 一级标题正文：#333333
- 次要说明文字：#666666
- 占位提示文字：#999999

### 背景与分割
- 页面整体背景：#F5F7FA
- 卡片背景：#FFFFFF
- 分割线颜色：#E8E8E8

## 2. 字体规范
- 中文优先：PingFang SC、Microsoft YaHei
- 英文数字：Helvetica、Arial
- 页面大标题：18px，font‑weight:bold
- 模块小标题：16px
- 普通正文、表格文字：14px
- 辅助小字、提示：12px

## 3. 图标规范
- 图标库：Ant Design Icons 线性图标
- 风格：简约细线，不要厚重填充图标
- 常用场景：统计图表、查询、新增、编辑、删除、返回、上传图片
- 图标尺寸：16px / 20px 两种规格

## 4. 布局与组件通用规则
- 页面外边距：16px
- 卡片圆角：6px
- 按钮圆角：6px
- 卡片内边距：16px
